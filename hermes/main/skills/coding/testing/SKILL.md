# Testing

Load **`vendor/superpowers/test-driven-development/SKILL.md`** when implementing new behavior.

## Must follow

1. Red → green → refactor when doing TDD.
2. Run the **smallest relevant test command** after changes (`core/verification`).
3. Do not delete or weaken tests to greenwash failures.
