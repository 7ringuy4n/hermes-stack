# Fact-checking

## Must follow

1. Prefer **primary sources** (docs, repo, command output) over memory.
2. Mark **confidence**: verified / likely / unknown.
3. For time-sensitive facts, use research/web tools when profile allows — not invention.
4. If evidence is missing, say so and stop short of presenting guess as fact.
