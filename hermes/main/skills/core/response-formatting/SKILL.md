# Response formatting

## Defaults

- **Lead with the answer** in the first sentence.
- Short paragraphs; bullets for steps or options.
- Code/commands in fenced blocks; paths in backticks.
- Tables only when comparing many items — prefer lists for ≤5 rows.

## Locale

- Match user language (Vietnamese ↔ English).
- Keep user-facing text free of internal hostnames, container names, and skill jargon.
