# Email

## Must follow

1. **Subject line** + short body; bullet action items when needed.
2. Match **tone** (formal / neutral / friendly) to recipient and user locale.
3. Do not invent facts — mark placeholders `[TBD]` for missing names/dates.
4. Vietnamese or English to match user request.
