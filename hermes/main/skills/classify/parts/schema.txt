OUTPUT SCHEMA — minified JSON only. Output ONLY these keys.

task_hint: normal|schedule|coding|tool|search|file|knowledge|unknown (never "chat")
execution_class: interactive|async|schedule
task_type: chat|media_generation|file_processing|create_schedule|list_schedule|delete_schedule|pause_schedule|resume_schedule|update_schedule|run_schedule|knowledge|search|tool|coding
response_mode: ack_then_deliver|confirm (never direct)
process_original_message: bool
message: string — inner work only on create_schedule
instructions: string array — one entry per distinct job
attachments_required: bool
attachment_types: image|file|audio|video array
skill: media_file|web_search|schedule|security|knowledge or null
skill_action: create|delete|list|pause|resume|update|run_now|deliver|process_file|generate_media|search|lookup or null
cadence: once|daily|weekly|monthly|yearly or null
schedule_form: once_at|once_after|recurring or null
delay_seconds: int or null — once_after only; seconds from request receipt
clock_hm: "HH:MM" or null — once_at only (24h digits)
cron_expr: five-field cron or null — recurring only
next_run_at: always null from classifier
timezone: Area/City or null
timezone_source: user_default|explicit or null
reference_time_source: schedule_request_received_at or null — once_after only
schedule_resolution: clear|needs_confirmation|ambiguous|invalid or null
confirmation_required: bool or null
schedule_selector: {id:null, name, match:{content_hint, time_hint}} or null — never invent id
target_channel: string or null — display name only
schedule_delivery: verbatim|process|transform or null
output_type: image|pdf|txt|docx|xlsx|csv|md or null
poster_n: int or null — text poster line count
poster_phrase: string or null — exact poster glyphs
poster_bw: bool or null
task_details: array of {task_type, output_type, depends_on?} when mixed or instructions length>=2
depends_on: 0-based int array
uncertain: bool (omit or false when sure)
missing: string array (time|destination|output_type) when uncertain
tasks: optional array of independent schedule objects. Each is a full create (task_hint, task_type, skill, skill_action, instructions, schedule_form, delay_seconds, clock_hm, cron_expr, cadence, target_channel, schedule_delivery, timezone_source, schedule_resolution). Use tasks[] when two+ creates have different clocks, delays, or destinations. Omit tasks[] for a single wrapper job.
