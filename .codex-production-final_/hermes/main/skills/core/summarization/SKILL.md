# Summarization

## Must follow

1. **Structure**: headline (1 line) → key points → optional detail.
2. Preserve **decisions, numbers, names, and open questions** from the source.
3. Do not add facts not in the source (`core/fact-checking`).
4. For long files, use document skills (`pdf`, `docx`, `xlsx`) or ingest — do not pretend to have read unseen content.
